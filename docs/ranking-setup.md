# みんなで競うランキングの設定手順

GitHub Pages には記録を保存する仕組みがないので、**Google スプレッドシート**を保存先にします。
Google Apps Script（スプレッドシートに付いている小さなプログラム実行機能）を「ウェブアプリ」として公開し、
ゲームからそこへ記録を送ります。無料で、所要時間は10分ほどです。

## 1. スプレッドシートを作る

1. [Google スプレッドシート](https://sheets.google.com) で空白のスプレッドシートを新規作成する
2. 名前を「漢字タワー ランキング」などにしておく（何でもよい）

## 2. ランキングのプログラムを貼り付ける

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身をすべて消す
3. このリポジトリの [`ranking-server/Code.gs`](../ranking-server/Code.gs) の中身をすべてコピーして貼り付ける
4. 💾（プロジェクトを保存）を押す

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** を押す
2. 「種類の選択」の ⚙ から **ウェブアプリ** を選ぶ
3. 次のように設定して **デプロイ** を押す
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「アクセスを承認」を求められたら、自分の Google アカウントを選んで許可する
   - 「Google はこのアプリを確認していません」と出たら **詳細 → （プロジェクト名）に移動（安全ではないページ）** で進む。
     自分で作ったプログラムなので問題ありません
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピーする

## 4. ゲームに URL を設定する

[`js/config.js`](../js/config.js) の `rankingUrl` にコピーした URL を入れて、公開しているブランチに反映します。

```js
window.KANJI_TOWER_CONFIG = {
  rankingUrl: "https://script.google.com/macros/s/……/exec",
};
```

GitHub の画面で `js/config.js` を開き、鉛筆アイコンから直接書き換えてもかまいません。
数分後に GitHub Pages に反映され、ランキングの表示が「みんなのランキング」に変わります。

## しくみと注意

- 1人1件（その端末での自己ベスト）を保存し、上位10件を表示します
- 記録は `scores` シートにたまります。いたずらの記録は、その行を削除すれば消せます
- 端末ごとにランダムな ID と合言葉を作ってブラウザに保存し、自分の記録だけを上書きできるようにしています。
  ブラウザのデータを消したり別の端末で遊んだりすると、別のプレイヤーとして登録されます
- 積んだ漢字の数と個数が一致しない記録は受け付けませんが、ゲームはブラウザ上で動いているので、
  本気で改ざんしようとする人を完全に防ぐことはできません
- `Code.gs` を書き換えたときは、**デプロイ → デプロイを管理 → ✏️ → バージョン: 新バージョン → デプロイ** で更新します
  （「新しいデプロイ」を作ると URL が変わってしまいます）
