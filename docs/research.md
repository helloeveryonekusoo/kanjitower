# 動物タワーバトルの調査メモと、漢字タワーへの置き換え

## 1. 動物タワーバトル（どうぶつタワーバトル）のゲーム構造

Yuta Yabuzaki 氏が開発した、物理演算を使う積み上げ対戦パズル（iOS / Android、のちに Nintendo Switch 版も発売）。

| 要素 | 内容 |
| --- | --- |
| 目的 | 動物をステージ（船・島のような台）の上に積み上げる |
| 敗北条件 | 自分の手番で、どれか1匹でも台から海へ落としたら負け |
| ピースの出方 | 動物は**ランダムで1匹ずつ**画面上部に出現（プレイヤーは選べない） |
| 操作 | 左右に動かして落とす位置を決める／**回転**させて向きを変える／指を離す（ボタン）と落下 |
| 物理 | 動物の形がそのまま当たり判定。摩擦・重心・慣性があり、挙動が読みにくいのが面白さ |
| ターン | 落とした動物が静止したら次の手番へ。対戦では交互、時間制限あり |
| カメラ | タワーが高くなるほど画面が上へスクロールし、出現位置も上がる |
| モード | 1対1オンライン対戦（レート制）／2〜4人のローカル対戦（Switch）／ひとりで積んだ数を競うスコアアタック |
| 戦術 | 回転して隙間にねじ込む、台の端に引っかける、あえて不安定に積んで相手のミスを誘う など |

ゲームループを抽象化すると次のようになる。

```
[ピース出現] → [位置・角度を調整] → [落下] → [物理シミュレーション]
      ↑                                              │
      └──── 全体が静止 ← 落下物なし ←─────────────────┤
                                                     └→ 何か落ちた → ゲーム終了
```

## 2. 漢字タワーへの置き換え

| 動物タワーバトル | 漢字タワー |
| --- | --- |
| 動物のシルエット | **漢字の字形**（フォントから当たり判定を自動生成） |
| ランダムに1匹出現 | **ランダムに3字提示 → 1字を選ぶ**（このゲーム独自の戦略要素） |
| 対戦（先に落とした方が負け） | **ひとりスコアアタック：何個積めたかを競う** |
| 船・海 | 「漢字の台」と「墨の海」 |
| 回転 | 45° ずつ回転（同じ） |

### 3字から選ぶ仕組み

候補は毎ターン、形の扱いやすさで分けた3グループから1字ずつ選ぶ（`js/kanji.js` の `t`）。

- **tier 1**: 口・田・皿・一・凹 など。輪郭が四角く平らで土台向き
- **tier 2**: 人・木・火・川 など。払いや足があり、置き方に工夫が要る
- **tier 3**: 鬱・龍・轟・鳥 など。画数が多く重い、またはデコボコが激しい

どの手番でも「安全な字」と「クセのある字」が並ぶので、
今のタワーの形に合う字を見極めて選ぶ、という判断が毎回発生する。

### 字形から当たり判定を作る方法（`js/shape.js`）

1. オフスクリーン canvas（256px）に太字で漢字を描く
2. 16×16 のマス目ごとにインクの被覆率を測り、30% 以上を「塗り」にする
3. 塗りマスを貪欲法で大きな長方形にまとめる（部品数を減らして物理演算を軽くする）
4. その長方形群を Matter.js の複合ボディにする

描画も同じ canvas 画像を使うので、見た目と当たり判定がずれない。
「三」「川」「心」のように離れた部品を持つ字も、ひとつの剛体として扱う。

### 物理演算の注意点

Matter.js は複合ボディの慣性モーメントを「各部品の慣性の単純和」で計算するため、
離れた部品を持つ字では慣性が極端に小さくなり、着地した瞬間に高速回転して吹き飛ぶ。
`createKanjiBody()` で平行軸の定理を使い、重心まわりの慣性モーメントを計算し直している。
